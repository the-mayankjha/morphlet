# Morphlet v1.4.1

Includes all v1.4.0 quick tools, multi-image PDF/Word exports, carousel previews, configurable scroll navigation, Studio editing controls, and verified update downloads.

## Fix
- Recognize Linux release asset architecture names `amd64` and `x86_64` as x64 when selecting DEB and AppImage updates. This matches the actual installer names generated by electron-builder.

## Downloads
macOS Apple Silicon and Intel DMG/ZIP, Windows x64 setup, and Linux x64 AppImage/DEB. SHA-256 checksums accompany each installer. macOS uses ad-hoc signing and manual DMG replacement without requiring Developer ID. Save your work before updating.
