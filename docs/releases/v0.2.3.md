# Morphlet 0.2.3

- New monochrome Morphlet application icons for macOS, Windows, and Linux, plus a template menu bar icon for macOS.
- Morphlet stays running in the background when Studio or the wheel closes. Reopen it through the menu bar or system tray; Quit Morphlet exits explicitly.
- Optional Launch at login setting for installed builds, including XDG autostart on supported Linux desktops.
- Added background lifecycle and Linux autostart regression tests; all 18 tests pass locally.
