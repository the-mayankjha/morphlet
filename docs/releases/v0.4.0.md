# Morphlet 0.4.0 — Structured Markdown and formatted PDFs

- PDF-to-Markdown now reconstructs detected ruled tables and fences monospaced code with inferred indentation.
- AI-ready bundle Markdown and chunks use the same structure, preserving code fences and table headers when splitting long content. Unreliably positioned tables are appended with an extraction note and original text retained.
- Markdown-to-PDF now renders heading sizes, bold/italic text, inline code, lists, task lists, shaded code blocks, tables with repeating headers, quotes, rules, links, and standalone local images.
- Includes removal of arrow icons throughout the app.

Validation: 26 automated tests, native Electron PDF bundle/Studio checks, and visual inspection of the generated Markdown formatting sample. Scanned/borderless tables, proportional-font code, merged cells and complex reading order can require manual correction. Remote images, LaTeX rendering and full multilingual font coverage are not included.
