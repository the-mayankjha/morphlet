# Morphlet v1.2.3

## Studio stability on macOS

- Prevent a native appearance notification from recursively rebuilding the Studio glass regions.
- Skip native material updates when the theme and layout have not changed.
- Keep file selections and previews stable when updating the glass surface; material-only updates no longer resend the complete Studio state.
- Avoid assigning an unchanged native window appearance.
- Add regression tests for repeated appearance notifications, theme switching and sidebar changes.

Includes the v1.2.2 macOS signature correction and strict app/DMG verification. Mac packages remain ad-hoc signed and unnotarized; Windows packages remain unsigned.
