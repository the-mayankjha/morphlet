# Morphlet v1.0.0

Morphlet brings local conversion, a quick conversion wheel, AI-ready PDF bundles and an integrated Studio PDF editor to macOS, Windows and Linux.

## Workspace polish

- Removed the transparent gutter between the Studio sidebar and PDF editor.
- Removed the unused footer strip beneath the editing workspace.
- Joined the editing panels to the window edges while keeping the file sidebar available.
- Kept properties controls within their panel and tightened toolbar spacing.
- Added Fit width alongside Fit page and percentage zoom.
- Added matching icons to the Studio file/results navigation.

## Included workflows

Convert images and documents, crop and resize images, export structured Markdown and AI-ready PDF bundles, edit supported original PDF text, remove or replace supported embedded images, annotate, fill standard forms and organize pages. Files are processed locally and originals are preserved.

PDF content editing remains conservative: scanned or complex text, nested/clipped/rotated image content and full paragraph reflow may be unsupported. Content removal is not secure redaction. Packages remain unsigned; macOS packages are not notarized. Desktop gesture support varies by platform and file manager.

## Validation

40 automated tests passed. Native desktop checks verified continuous scrolling, original text editing, both themes, saving and returning to conversion. Layout measurements confirmed zero sidebar/header/bottom gaps and no properties-panel button overflow.
