# Morphlet v1.1.0

- Add native File, Edit, View, Window and Help menus for Studio, with a Morphlet application menu on macOS and visible window menus on Windows/Linux.
- Connect file, conversion, PDF save/search, history, theme, zoom and help actions to the existing Studio controls and standard shortcuts. Inapplicable commands are disabled.
- Show the Morphlet Dock icon while Studio is open on macOS and explicitly retain taskbar presence on Windows/Linux.
- Retain the tray/menu-bar icon throughout the app session, use a macOS template icon after resizing, and support tray double-click to open Studio.
- Set Morphlet application/About branding and the Windows app model identity.

Validation: 43 automated tests passed, including menu templates for all three platforms. Native macOS checks exercised menu actions, command availability, PDF saving, themes, Dock visibility, hiding and reopening Studio. Windows/Linux interactive menu and tray behavior still needs device testing; Linux requires desktop tray support.
