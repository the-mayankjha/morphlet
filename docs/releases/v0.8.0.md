# Morphlet v0.8.0

## Original PDF images

Click a supported embedded image in Studio’s PDF editor, then choose Remove image or Replace image. Replacements preserve proportions and fit inside the original bounds. Undo restores removals; Restore original reverts replacements.

Only the selected placement changes, so other uses of a shared image remain intact. Image and original-text edits can be saved together. Originals are never overwritten.

This release supports page-level, axis-aligned raster image XObjects. Inline images, masks, clipped images, arbitrary rotations and images nested in Form artwork remain unsupported. Removing content is not secure redaction.
