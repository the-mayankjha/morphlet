# Morphlet v0.7.0

Studio now has separate Edit and Annotate tools, a cleaner contextual inspector, and an annotation sidebar.

- Replace or delete supported original PDF text without covering the page background.
- Add native comments, highlights, underlines, strikeouts, freehand ink and rectangles.
- Reopen, update and delete supported saved annotations without duplicating them.
- Open converted PDF results directly in the editor.
- Keep advanced geometry and page actions tucked away until needed.

Text replacement supports conservatively mapped horizontal text runs using standard replacement fonts. Complex or scanned text remains read-only. Paragraph reflow and secure redaction are not included.

Validation: 38 automated tests passed, plus native desktop checks for text replacement, annotations, saved-file reopening, light/dark themes, images, links, page operations, forms and signatures.
