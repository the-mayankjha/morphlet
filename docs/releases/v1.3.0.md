# Morphlet v1.3.0

## Select files, then tap one key

- On macOS, select files in Finder and press and release Cmd on its own.
- On Windows, select files in an active File Explorer window and press and release Ctrl on its own.
- Change the modifier or disable this gesture in Studio → Settings.
- Other key combinations and modifier-click selection are excluded from the gesture.
- Fix installed Windows selection/drag helper packaging by shipping the PowerShell script outside app.asar.
- Keep Option/Alt-drag as a separate drag gesture.

## GNOME Files integration

In the installed Linux app, open Studio Settings and choose Install GNOME Files action. Select files in Nautilus, right-click, then Scripts → Morphlet to open the selected local files directly in the wheel. Requires Python 3. GNOME Wayland restricts global modifier-only capture, so Ctrl-only is not promised there; use the Files action or Studio drag/drop.

## Validation and distribution

51 automated tests pass locally, and the implementation passes macOS Apple Silicon, macOS Intel, Windows x64 and Linux x64 package builds. Windows CI checks the installed helper; trusted macOS builds verify app signatures and DMG contents. Interactive desktop gesture testing is still needed across system configurations.

macOS packages remain ad-hoc signed without Apple notarization. Windows installers remain unsigned.
