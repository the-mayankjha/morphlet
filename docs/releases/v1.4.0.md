# Morphlet v1.4.0

## Quick tools
- Tap Shift for conversion options, and Cmd on macOS or Ctrl on Windows for editing tools. Configure the selection keys in Studio Settings.
- Compact Liquid Glass tool popups offer crop, resize, quality, mirror, flip, frames, compression, and solid-color background removal.
- Combine selected images into a PDF or Word document, with a custom filename, carousel preview, and a drag-to-reorder popup. Each image becomes a page; Word exports retain images rather than extracting editable text.
- Open in Studio exposes image controls and the full PDF editor. PDF quick tools include merging, page rearrangement, text additions, and lossless structural optimization.
- GNOME Files supports separate Morphlet and Morphlet Tools actions. Global modifier-only gestures remain restricted on Wayland.

## Interface and reliability
- Quick windows keep only the close control on macOS.
- The wheel center displays a file-type icon, or the Morphlet logo when empty.
- Mouse-wheel and touchpad scrolling select options throughout the popup. Press Enter to choose; disable scroll navigation in Studio Settings if preferred.
- Fix a macOS SIGTRAP caused by Electron's native file-icon lookup.

## Updates
- Check for newer stable releases from Studio Settings, Help, or the tray.
- Installed builds check on startup and every six hours, with one notification per new release. Automatic checks can be disabled.
- Download installers on request, with progress and SHA-256 verification before opening them.
- macOS uses a DMG replacement flow without requiring Developer ID. Windows opens its setup installer; Linux opens the DEB installer or reveals an AppImage for manual replacement. Save your work before updating.

## Downloads
macOS Apple Silicon and Intel DMG/ZIP, Windows x64 setup, and Linux x64 AppImage/DEB. Checksums accompany each installer. macOS builds use ad-hoc signing and are not notarized; first launch may require approval in Privacy & Security.
