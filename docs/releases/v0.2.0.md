## Morphlet Studio

A dedicated workspace alongside the quick conversion wheel:

- File queues, per-file settings, batch conversion, and an output-folder picker.
- Large original/converted previews for images, PDF first pages, and text.
- Image cropping with aspect presets, resizing, quality, flip, and mirror.
- Session result history, reveal actions, and a shortcut back to the wheel.

Open Studio from the tray/menu bar or the wheel’s **Studio ↗** button.

## Monochrome Liquid Glass

Shared, saved light and dark themes use strictly black-and-white controls. Native macOS glass now follows the selected theme consistently, including the header and action buttons. Studio uses native Liquid Glass on macOS 26+; other systems have a monochrome fallback. Original file previews retain their colors.

## Wheel and dragging

More visible opening/selection animation, scroll-to-select, quiet tick sounds, and saved mute preferences. The wheel keeps a continuous circle and fixed drop targets.

- **macOS:** Option-drag and Finder selection with Option+C.
- **Windows:** Alt-drag monitor with Explorer selection support; unknown sources open a drop target first.
- **Linux X11:** Alt-drag adapter for local file URI payloads; unavailable payloads use the drop target.
- **Wayland or unsupported desktops:** use the tray’s floating drop target or Studio. Global drag monitoring is restricted by the compositor.

The Windows/X11 adapters receive automated build/init checks; file-manager-specific gestures still need interactive testing on those platforms.

## Downloads

macOS ARM64 and Intel DMG/ZIP, Windows x64 installer, and Linux x64 AppImage/DEB. Each installer includes a SHA-256 checksum.

Packages are unsigned; macOS packages are not notarized. PDF-to-image export uses page 1; scanned-PDF OCR and animated image export are not included. Originals are preserved.
