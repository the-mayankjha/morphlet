# Morphlet v1.2.2

## macOS packaging fix

- Fix incomplete app-bundle signatures that could cause macOS to report Morphlet as damaged or corrupted even when the DMG checksum was valid.
- Explicitly ad-hoc sign the app and nested code, with the Electron entitlements required for this signing mode.
- Verify the packaged app with strict, recursive code-signature validation before uploading artifacts.
- Verify each DMG checksum, mount it read-only, and verify the app inside before publication.

## Downloads

Includes Apple Silicon and Intel macOS DMG/ZIP packages, a Windows x64 installer, and Linux x64 AppImage/DEB packages. SHA-256 checksum files accompany the downloads.

Ad-hoc signing provides bundle integrity, not an Apple Developer ID. macOS builds remain unnotarized and may still be blocked by Gatekeeper. Windows installers remain unsigned. This release does not change Windows or Linux application behavior.
