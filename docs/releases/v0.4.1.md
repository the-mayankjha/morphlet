# Morphlet 0.4.1 — PDF Markdown hierarchy

- Infer document titles, chapters, sections and subsections from document-wide typography, weight, spacing and numbered section depth.
- Use consistent Markdown heading levels across pages and join wrapped headings with matching style.
- Remove repeated running headers and page-number footers from structured Markdown.
- Preserve physical page references as comments instead of adding fake page headings to the outline.
- Include per-page detected headings in AI-ready manifests. Tables and code blocks remain supported.

Validation: all 27 automated tests pass, including a real three-page hierarchical PDF; native Electron six-page export and preview checks pass. Heading levels are inferred from layout, with up to 12 representative pages sampled; ambiguous or scanned source documents may require correction.
