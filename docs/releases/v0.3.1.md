# Morphlet 0.3.1 — Liquid Glass conversion progress

- The quick wheel is replaced by a compact monochrome glass progress panel while conversion runs.
- PDF bundles report completed pages, OCR stages, and packaging; other conversions show file progress and an activity sweep for unknown durations.
- Results appear after the initial preview is ready. Failed conversions restore the wheel and show the error.
- Native macOS glass bounds follow the progress panel; both themes, keyboard accessibility and reduced-motion preferences are supported.

Validation: 22 automated tests; browser checks for both themes, progress values, preview handoff, error recovery and reduced motion; native Electron export of the six-page test book with actual progress events and bundle preview.
