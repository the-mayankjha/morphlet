# Morphlet 0.3.0 — PDF books for AI agents

- New AI-ready PDF ZIP export in Studio and AI PACK in the wheel.
- Selected pages retain page-labelled text, full page PNGs including vector diagrams, extracted bitmap figures, detected table JSON, and smaller Markdown chunks.
- Source/file hashes and per-page extraction notes in a manifest; an included README explains how to supply text and page images to an agent.
- Page ranges, three visual detail levels, progress, cancellation, and converted-bundle summary preview in Studio.
- Optional local OCR for low-text pages using installed Tesseract and language data. No OCR software/models are downloaded or bundled; scanned pages remain available as images.
- Plain PDF TXT/Markdown exports now preserve physical page labels.

Validated with 22 automated tests, a real native Studio export of an illustrated two-page document, and independent ZIP integrity checks. Complex reading order, OCR, equations and tables still require checking against the exported page images. Unzip before uploading; Markdown links alone do not upload the linked images.
