# Morphlet v0.9.0

- PDF editing now lives inside Studio, sharing the header and file sidebar instead of opening a modal workspace.
- Scroll continuously through PDF pages; the page list also scrolls. The page nearest the center becomes editable when scrolling settles.
- Nearby page previews load on demand with at most two preview requests in flight. Offscreen previews are released, and draft additions remain visible on nearby pages.
- Monochrome SVG icons accompany editing, annotation, image and page tools.
- The Studio header uses the Morphlet wordmark without the m badge.
- Light mode has a translucent white header backing and darker labels for contrast over busy backgrounds.

Validation: 40 automated engine tests passed. Native desktop checks cover continuous scrolling to another page, text editing, both themes, save and return to conversion, plus image replacement and reopening the editor.
