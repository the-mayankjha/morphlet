# Morphlet 0.6.0 — PDF editing in Studio

Select a PDF in Studio and choose Edit PDF to open the new editing workspace.

- Add selectable text, images, real clickable links, translucent highlights, outlined rectangles and drawn signatures.
- Drag/resize additions; adjust fonts, sizes, bold/italic and colors; preserve image proportions; duplicate, layer and delete additions.
- Undo/redo and keyboard shortcuts, page navigation, zoom and embedded-text search.
- Rotate/reorder/duplicate/delete ordinary pages, insert blank pages and merge ordinary PDFs.
- Fill standard interactive text, checkbox, dropdown, radio and option-list form fields.
- Save to a new edited copy, preserving the source; results appear in Studio history.

Validation: 35 automated tests; native desktop checks covering editing, images, links, both themes, undo/redo, page operations, merging, search, actual saved nine-page PDFs, form values/widget appearances, signatures and saved-PDF rendering.

This release adds content over existing pages. Embedded paragraph replacement/reflow, secure redaction, certificate signing, XFA and encryption management are not included. Drawn signatures are visual marks. Standard text fonts support Latin characters. Interactive-form pages must be retained exactly once; their duplication/deletion and interactive-form merging are blocked to protect field relationships. Drafts remain session-local.
