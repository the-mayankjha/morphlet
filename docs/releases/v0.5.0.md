# Morphlet 0.5.0 — SVG export and image fidelity

- Raster images can export to SVG. Default lossless mode embeds PNG pixels; Studio also offers editable-path tracing for logos and illustrations.
- Vector tracing runs in a background worker, supports Studio cancellation, and is limited to 1 megapixel after edits. Its 64-color approximation can change appearance; lossless mode retains raster detail.
- SVG-to-image conversion rasterizes at the requested width for sharp larger output, including transparency where the destination supports it.
- Quality defaults to 100. PNG avoids palette quantization; TIFF uses LZW; WebP/AVIF use lossless encoder modes at 100; JPEG uses 4:4:4 chroma but remains lossy. Original resolution and ICC profiles are retained where supported.
- SVG output previews work in Studio and the quick wheel.

Validated with 31 tests, including exact tested pixel comparisons, high-resolution SVG rasterization, real vector path output, and native Studio mode selection, tracing and preview checks. A raster-to-SVG container cannot add detail to a source image, and tracing is not pixel-perfect.
