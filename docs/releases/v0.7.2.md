# Morphlet v0.7.2

Original PDF text can now be clicked directly in Select mode. The properties panel shows the number of editable text regions and explains how to edit existing content. Replacement text updates live on the page while typing, with grouped undo for each text-editing focus.

Verified directly against the cover title of bv_cvxbook.pdf and with the native desktop regression for replacement, annotations, saving and reopening. Unsupported page layouts still show a read-only explanation.
