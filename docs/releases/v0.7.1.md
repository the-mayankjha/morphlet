# Morphlet v0.7.1

Fix original PDF text detection when a visible line is split across adjacent text-show operations. The editor now maps the combined line and removes every original operation before writing replacement text.

Edit PDF now opens with Edit text enabled, so supported original text regions are immediately selectable. Read-only page messages distinguish unsupported layouts from scanned text.

Validation: 39 automated tests passed, including a fragmented-content regression that verifies actual saved text replacement and surrounding text preservation. Native desktop checks passed for editing on open, replacement, annotations and saved-file reopening in both themes.
